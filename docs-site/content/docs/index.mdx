TRACERA is an **agentic code intelligence engine** that lives in your
terminal. It indexes your codebase into a hybrid retrieval index, answers
questions about architecture, and can autonomously plan, edit, and verify
code changes — all through a TUI driven by slash commands.

## What works, out of the box

TRACERA ships **85 slash commands**, **58 registered tools**, and a TUI
with live streaming, attachments, a provider switcher and a command
palette. Everything below is live in the current build — every item maps to
a command you can run (see the [Slash Commands reference](/docs/slash-commands)
and [The TUI](/docs/tui)).

### Hybrid retrieval

- **Local semantic index** — every source file is parsed with tree-sitter,
  chunked, and embedded with sentence-transformers. Nothing leaves your
  machine; the index lives in LanceDB under `.tracera/`.
- **BM25 + dense fusion** — keyword and semantic retrieval run together,
  scores normalized, fused, and boosted by structural signals.
- **Score transparency** — every hit shows file path, line range, matched
  symbol, and the score breakdown, so you can tell *why* it ranked.
  (`/search`, `/debug`, `/ranked`, `/index`)

### Structural analysis

- **Symbol graph** — references, call hierarchy, and imports extracted from
  the AST, not regex guessing.
- **Blast radius** — transitive impact analysis across callers and entry
  points before you touch anything risky. (`/blast`, `/refs`, `/callers`,
  `/importers`, `/deps`, `/endpoint`)
- **Risk & quality metrics** — dead-code detection, complexity × churn
  hotspots, PageRank importance, coupling, and dependency cycles.
  (`/deadcode`, `/hotspots`, `/pagerank`, `/risk`, `/coupling`, `/cycles`)
- **Refactor preflight** — rename/move/extract plans plus edit/delete
  safety checks. (`/refactor`, `/editsafe`, `/deletesafe`)

### Autonomous coding

- **Fix loop** — `/fix` runs plan → retrieve → edit → test and iterates
  until checks pass or the budget is exhausted.
- **Coding tasks with full tool access** — `/code` executes multi-step
  changes; `/plan` and `/plantask` scope them first.
- **Regression gate** — the suite runs against a stashed baseline and the
  current state, so you know an agent change didn't silently break
  anything. (`/review`, `/selfreview`, `/regression`, `/test`)

### Multi-agent fleet

- **Five role-specialized sub-agents** — Researcher, Coder, Tester,
  Reviewer, Debugger, orchestrated by `/delegate`.
- **Hard sandbox** — sub-agents have no git tool and `run_command` rejects
  mutating git operations (`commit`, `push`, `reset`, `rebase`,
  `checkout`, ...). The main agent retains full access.

### Persistent memory

- **Typed records** — facts, decisions, preferences, and learned skills,
  embedded and linked into a knowledge graph for associative recall.
- **Session-to-session continuity** — relevant memories are injected at
  launch and steer tool use during tasks. (`/remember`, `/recall`,
  `/memory`, `/memgraph`, `/forget`, `/triples`)

### MCP integration

- **Server** — `tracera mcp serve` exposes the full tool registry (58
  tools) to any MCP client: Claude Desktop, editors, other agents.
- **Client** — consume external MCP servers and merge their tools into the
  registry, where they become slash-addressable automatically.

### Observability & evaluation

- **Live telemetry** — LLM/tool/retrieval call counts, token usage,
  latency, and estimated cost, in the TUI and the CLI.
- **Retrieval benchmarks** — Recall@k, MRR, nDCG and latency for grep vs
  BM25 vs dense vs hybrid vs +reranker, on a reproducible dataset.
- **Agent benchmarks & ablations** — end-to-end success/iterations/cost,
  and arm comparisons (+BM25 / +Dense / +Hybrid / +Graph). (`tracera eval`)

### Safety controls

- Shell command allowlist and confirmation policy (`TRACERA_ALLOWED_SHELL_COMMANDS`,
  `TRACERA_REQUIRE_CONFIRMATION_FOR`), command/test timeouts, workspace
  boundary enforcement for MCP file tools, and provider failover across 11
  LLM providers (including fully-local Ollama).

```
               │                                               │
      ┌────────▼────────┐                            ┌─────────▼─────────┐

```
