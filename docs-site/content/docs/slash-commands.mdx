Everything in the TUI is a slash command. Type `/` for autocomplete with
descriptions, or `/features` to list the full surface grouped by category.

| Command | Description |

| `/status` | Provider, model, tokens, memory status |

## Running any tool

Every registered tool is also reachable directly:

```bash
/tool <name> [key=value ...]      # run any registry tool
```

Tool aliases (like `/search` → `hybrid_search`, `/blast` →
`blast_radius`) are generated from the tool registry, so new tools appear
in autocomplete automatically.
